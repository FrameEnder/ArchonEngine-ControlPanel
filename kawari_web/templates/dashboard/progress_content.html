Every duty and open-world zone in your game install's content index (built {{ index_time }}), against the active build{% if build %} ({{ build }}){% endif %}. A duty is scripted when the build has its content script (resources/scripts/content/<short code>.lua, what the server runs when the duty starts) and has spawns when a drop-in adds its enemies; done means both. A zone has spawns when a drop-in adds its monsters (without one, the zone is empty). This is what the server has, not how well it plays: a script can still be rough, and the fork's documentation says how far each one goes.
