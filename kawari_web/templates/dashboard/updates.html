Build from source

The checkout's absolute path on the host — the machine running Podman — not inside this app's container. It is mounted into the builder read-only and synced to a separate build area, so your target/, databases and config are left alone.

Kawari's release profile is LTO with one codegen unit — the smallest binary, at the slowest compile, with no incremental rebuilds. Fast mode turns those off. Untick it to build exactly as CI does.
