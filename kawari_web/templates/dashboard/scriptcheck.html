Script Check

Checks the scripts the server runs for NPC conversations, menus and the shops they open (CustomTalk) and for the city openings against the client's own scripts for them: scenes the server plays that the client doesn't have, constants with another value than the client's, parameter names the game data doesn't have, client scenes never played, and the scripts' TODO notes. Quests are checked on Quest Lab.
