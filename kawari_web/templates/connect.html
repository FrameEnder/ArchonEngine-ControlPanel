How to connect

{{ branding.site_name }} is a Kawari server. You need the Windows FFXIV client and the Astra launcher (Astra runs the Windows client under Wine on Linux).

{% if info.mode == 'local' %}

This server is currently in local-only mode: it advertises 127.0.0.1, so only the machine running it can connect. An administrator needs to switch it to LAN/Tailscale mode for remote players.

{% endif %}

1. Get an account

{% if user %}

You are signed in as {{ user.display_name or user.username }}. Use that same username and password in the launcher - it is the same account.

{% elif info.registration_open %}

Create an account

One account covers both: the credentials you make here are the ones you type into the launcher.

{% else %}

Registration is closed on this server. Ask an administrator to create an account for you, then sign in.

{% endif %}

2. Point Astra at this server

  1. Astra → Settings → General → enable Show Developer Settings.
  2. Go to Settings → your account → the Servers tab.
  3. Paste this into Autoconfig Server URL:
    {{ info.autoconfig_url }}
  4. Press Download Configuration. The server fields fill in automatically.
  5. Log in with your account. Leave Lodestone, Save Data Bank and Data Center Travel empty - this server does not use them.

Troubleshooting

Astra cannot fetch the configuration
The server is offline, or port {{ info.web_port }} is blocked by a firewall.
Login works but the world never loads
The world server address is wrong or unreachable - an administrator can check it on the dashboard.
The patch server refuses the login
Your game client is newer than the server supports. The server currently targets {{ stats.patch or 'an unknown patch' }}.
